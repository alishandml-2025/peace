Reflection

Working on this SDG 16 coursework has been a transformative learning experience. Creating the user profile page taught me about progressive JavaScript interaction and DOM manipulation, while the SVG sitemap challenged me to think about visual hierarchy, accessibility, and responsive scaling. Collaborating with my teammates helped me develop communication and project management skills that will be invaluable in my future career. I particularly enjoyed solving the challenge of making the SVG sitemap accessible via keyboard navigation, which required careful use of tabindex, focus states, and ARIA attributes. This project reinforced my understanding of how web technologies can be used to promote awareness about critical global issues like peace, justice, and strong institutions.
